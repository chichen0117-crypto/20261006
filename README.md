# 面膜相關檔案下載

依洛嘉（E.L.G）面膜商品連結列表網頁。

## 內容

- `index.html`：「面膜相關檔案下載」網頁，列出依洛嘉官網搜尋「面膜」的 21 項商品，以商品名稱作為連結名稱，點擊即開啟官網對應頁面。

## 資料來源

- 依洛嘉面膜保養官方旗艦店：https://www.elg.com.tw/
- 商品清單取自官網「面膜」搜尋結果（2026-10-20）。
- 其中 6 項商品在搜尋頁沒有商品頁網址，連結改為以該商品名稱在官網站內搜尋。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需安裝任何套件。

## 更新

官網商品有增減時，重新整理清單並更新 `index.html`。
